 📡 AirChat - Local Mesh Network Messenger

 📝 Project Overview (فكرة المشروع)
AirChat هو تطبيق محادثات موبايل مخصص لنظام الأندرويد، يعتمد كلياً على التواصل داخل الشبكة المحلية (Local Area Network - LAN). يتيح التطبيق للمستخدمين التواصل الفوري واكتشاف الأجهزة المتصلة على نفس شبكة الـ Wi-Fi دون الحاجة لاتصال بالإنترنت، مما يضمن سرعة عالية وأماناً واستمرارية في الاتصال حتى عند انقطاع الخدمة الخارجية.

---

 🎯 Key Features & Objectives (أهداف وميزات المشروع)
*Local Discovery: الاكتشاف التلقائي السريع للمستخدمين المتصلين بنفس الشبكة وعرض اسم الشبكة الحالية (SSID).
*Direct Messaging (1-to-1): إمكانية اختيار أي مستخدم متصل والبدء بمحادثة خاصة معه فوراً.
* Group Chats:** إنشاء وانضمام لغرف المحادثات الجماعية داخل الشبكة المحلية.
* Navigation Drawer & Customization: قائمة جانبية شاملة لإدارة البروفايل (تغيير اسم الجهاز) وتخصيص الواجهة (الوضع الداكن Dark Mode / الوضع الفاتح Light Mode).
* Zero Internet Reliance:** الاعتماد الكامل على بروتوكولات الشبكات المحلية (UDP Broadcast & TCP Sockets) بلغة بايثون.

 🏗️ Project Structure (هيكلية المشروع)

AirChat/
├── assets/
│   ├── icons/                    # التطبيق وأيقونات الواجهة
│   └── themes/                   # أنماط الألوان (Dark/Light Mode styles)
├── config/
│   └── settings.py               # إعدادات المنافذ (Ports) والأنماط التلقائية
├── network/
│   ├── discovery.py              # الخدمة المسؤولة عن البث والاكتشاف الآلي عبر UDP
│   ├── server.py                 # سيرفر استقبال الرسائل المباشرة عبر TCP
│   └── client.py                 # عميل إرسال الرسائل الفردية والجماعية
├── ui/
│   ├── components/
│   │   ├── sidebar.py            # القائمة الجانبية (Navigation Drawer والإعدادات)
│   │   ├── user_card.py          # مكون عرض قائمة المتصلين والمجموعات
│   │   └── chat_bubble.py        # مكون فقاعات الرسائل
│   └── screens/
│       ├── home_screen.py        # الشاشة الرئيسية (اسم الشبكة + قائمة الأفراد والجروبات)
│       └── chat_screen.py        # شاشة تبادل الرسائل المباشرة
├── utils/
│   └── network_info.py           # دوال استخراج اسم الشبكة الحالية وعنوان الـ IP
├── main.py                       # نقطة انطلاق التطبيق (Kivy App Entry Point)
├── buildozer.spec                # ملف إعدادات بناء حزمة الأندرويد (APK)
├── requirements.txt              # المكتبات المطلوبة للتشغيل
└── README.md                     # توثيق المشروع وخطة العمل
